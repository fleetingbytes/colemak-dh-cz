# Colemak Layout for Czech

Using the US-American Colemak DH ISO layout, it is possible to type Czech character, but they are not readily accessible. Heavy use of dead keys and layer 3, layer 4 is necessary. The schemas below show the basic keyboard keys with their four layers of mappings like this for each key:

```
┌─────┐
│bd···│
│ac···│
└─────┘
```

Where `a`, `b`, `c`, `d` represent the character mapped and layer 1 through layer 4:

- `a`: layer 1 (unshifted)
- `b`: layer 2 (shifted)
- `c`: layer 3 (AltGr)
- `d`: layer 4 (AltGr, shifted)

### Motivation

- Every Czech letter should be typable in one to three keystrokes (including dead keys and layer shifts)
- Most frequent Czech letters shall be preferred to easily accessible numbers on the top row
- Frequent Czech letters shall be preferred to easily accessible `Q`, `W`, `X`, `F` very rare in Czech texts.
- Preserve the of dead keys of the US colemak layout in their original positions
- Prefer to move rarely used special characters to some of the `asciitilde` places, rather than to lose them entirely
- Add a few rare special characters in favor of an extra way to type `asciitilde`


## Changes with regards to Colemak-DH (ISO)

- Every character typable on Colemak-DH (ISO) is also typable on Colemak-DH (ISO), although some of them moved to other mappings. Ultimately, almost all of the extra ways how to write `asciitilde` have been repurposed for something more useful.

### Summary

In the following, the target key locations are named after their standard Colemak mapping. Thus, when I say something like "`X` moved to layer 3 of `U`" this means that the character `X` moved to layer 3 of that key where the Colemak-DH (ISO) layout has `U`, not where the US QWERTY layout has `U`.

#### Regular Characters

- numbers stayed on their keys but moved to layer 3
- `Q` now types `Č`
- `W` now types `Ž`
- `F` now types `Ř`
- `X` now types `Š`
- original Colemak `Q`, `W`, `F` stayed on their keys but moved to layer 3
- original Colemak `X` moved to layer 3 of `U`
- original Colemak `1234567890` now type `ďťůéáňúýěí`
- Czech `ĎŤŮÉÁŇÚÝĚÍ` have to be typed through dead keys or layer 3

#### Special characters

- `¡` moved to `AltGr-Shift-/`
- `¹` moved to `AltGr-Shift-x`
- `º` moved to `AltGr-Shift-g`
- `²` moved to `AltGr-Shift-r`
- `ª` moved to `AltGr-Shift-m`
- `³` moved to `AltGr-Shift-d`
- `¢` moved to `AltGr-Shift-6`
- `€` moved to `AltGr-Shift-3`
- `ħ` moved to `AltGr-Shift-h`
- `Ħ` moved to `AltGr-Shift-k`
- `ð` moved to `AltGr-Shift-,`
- `Ð` moved to `AltGr-Shift-.`
- `þ` moved to `AltGr-\`
- `Þ` moved to `AltGr-Shift-\`
- `‘` moved to `AltGr-Shift-1`
- `’` moved to `AltGr-Shift-2`
- `äÄåÅãÃ` must be written with the help of the corresponding dead key
- `‽` added at `AltGr-Shift-b`
- `§` added at `AltGr-Shift-7`
- `‰` added at `AltGr-Shift-8`


## Definition of Colemak-DH (ISO) in /usr/local/share/X11/xkb/symbols/us:

```
xkb_symbols "colemak_dh_czech_iso" {

    // Modified Colemak-DH (ISO) layout with easy access to all
    // Czech symbols.
    // http://github.com/fleetingbytes/colemak-dh-iso-cz

    include "us(colemak_dh_iso)"
    name[Group1]= "Czech (Colemak-DH ISO)";

    key <AE01> { [       dcaron,       exclam,               1,      leftsinglequotemark ] };
    key <AE02> { [       tcaron,           at,               2,     rightsinglequotemark ] };
    // Grok please continue here
};
```
